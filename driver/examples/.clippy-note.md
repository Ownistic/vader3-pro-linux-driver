The probe examples under `examples/` deliberately use `transmute` to resolve SDL
symbols at runtime through `dlopen`, and they contain exploratory code that is
kept because the measurements in `docs/evidence/` cite it. They are diagnostic
tools, not part of the library or daemon, so lint strictness is applied to `src/`
and `tests/` only.

Verify the shipped code with:

    cargo clippy --lib --bins --tests
